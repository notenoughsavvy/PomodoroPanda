# PomoPulse - Focus Timer & Productivity Tool

PomoPulse is a sleek, responsive single-file web application built with HTML5, Tailwind CSS, and vanilla JavaScript. It implements the Pomodoro Technique to help users stay focused, boost productivity, and manage work/break intervals effectively.

## Key Features

- **Real-Time Countdown Engine:** Built using native JavaScript timing logic (`setInterval` / `clearInterval`) for smooth, accurate timekeeping.
- **Animated SVG Progress Ring:** Visual countdown circle that smoothly updates every second as time elapses.
- **Multi-Mode Support:** Switch effortlessly between:
  - **Pomodoro Mode:** 25-minute deep work focus session.
  - **Short Break:** 5-minute quick rest.
  - **Long Break:** 15-minute extended rest.
- **Interactive Controls:** One-click Start, Pause, and Reset functionality with dynamic icon states (Lucide icons).
- **Zero External Dependencies:** Built with pure JavaScript without heavy external libraries or frameworks.

## Getting Started

1. Download or clone `index.html`.
2. Open `index.html` directly in any standard web browser.
3. Click **Start Session** to begin your timer!
